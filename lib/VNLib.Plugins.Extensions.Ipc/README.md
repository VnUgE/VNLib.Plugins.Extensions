# VNLib.Plugins.Extensions.Ipc

Provides inter-plugin communication (IPC) via shared memory export bridges, enabling managed object sharing across plugin assembly boundaries within the same process.

Documentation, specifications, and setup guides are available on my website here:

[Builds and Source](https://www.vaughnnugent.com/resources/software/modules/VNLib.Plugins.Extensions)
